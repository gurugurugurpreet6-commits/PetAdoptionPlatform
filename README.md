# 🐾 Online Pet Adoption Platform

A Java Swing-based desktop application designed to make pet adoption easier by connecting adopters with animal shelters.

## 🚀 Project Overview

The Online Pet Adoption Platform provides a centralized interface for browsing pets and managing adoption-related activities.

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Maven
- IntelliJ IDEA

## 👥 User Modules

### Admin
- Admin dashboard
- Platform management
- Pet listing management
- Analytics and settings

### Shelter
- Manage pet listings
- Handle adoption-related activities

### Adopter
- Browse available pets
- View pet details and images
- Access adoption-related features

## 📁 Project Structure

- `src/` – Java source code
- `pet_images/` – Pet images
- `database.sql` – Database setup script
- `pom.xml` – Maven configuration
- `README.md` – Project documentation

## ⚙️ Requirements

- Java JDK
- IntelliJ IDEA
- MySQL Server
- Maven

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL Server.
4. Execute the provided `database.sql` script.
5. Configure database credentials in the application's database connection class.
6. Load Maven dependencies.
7. Run the `Login` class.
